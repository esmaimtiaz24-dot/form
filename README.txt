FOREVER CHEMICAL(SMC) PVT LTD — Inquiry Form

HOW TO USE
1. Extract this ZIP file.
2. Keep index.html and forever-chemical-logo.png in the same folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
4. Complete the form and test the validation.

VALIDATION INCLUDED
- Name required and validated.
- Phone field allows digits and an optional leading + only; requires 7–15 digits.
- Email format validation.
- Chemical/product name and message required.
- Simple arithmetic human-verification challenge.
- Required consent checkbox.

IMPORTANT
This is a front-end form. It validates entries in the browser but does not email, upload, or save submissions. To receive inquiries, connect a secure server-side backend and database (or a trusted form service). Browser-side validation alone is not security verification.
